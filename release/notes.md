Font packages, one zip per format:

| Format | For |
|---|---|
| `otf`, `ttf` | macOS, Windows, most applications |
| `woff2` | Web pages |
| `otb` | Linux desktops (GTK, Pango) |
| `bdf`, `pcf` | X11 applications, terminals |

Each zip contains Platinum Sans and Platinum Sans Small, each in SC, TC, JP
and KR (the regional forms of the East Asian glyphs), Regular and Bold,
with OFL.txt, NOTICE.md and the licenses of the sources.

The faces are drawn on a 12px grid: use them at 12px or a multiple of it.

The Go packages of this version: `go get github.com/firede/platinum-fonts@<tag>`.
